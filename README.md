# 2026 电赛 D 题：陆空无人系统协同

> 省级一等奖项目。仓库仅保留可编辑的比赛源码、必要协议资料与可核查的测试文档；构建产物、运行缓存、双臂小车 CAD 与无关 YOLOv5 工程不纳入。

## 项目组成

| 目录 | 职责 | 核心实现 |
| --- | --- | --- |
| [`car/`](car/) | STM32F103ZET6 小车控制 | 灰度循迹、编码器速度辅助、雷达/陀螺仪姿态限位、LoRa 协同、A 点减速停车保护 |
| [`aircraft/`](aircraft/) | 无人机与地面站 | ESP32 空端桥接、ANO 飞控任务状态机、投掷与动态起降阶段、树莓派地面站 |
| [`vision/`](vision/) | MaixCAM2 下视视觉 | 小车平台大圈识别、相对 X/Y 偏移回传、投放定位与动态起降引导 |
| [`docs/`](docs/) | 项目资料与证据 | 赛题要求、通信接口规范、联调/计分矩阵、灰度循迹测试和地图图片 |

## 协同边界

- 小车以灰度循迹为主导，编码器、雷达和 yaw 只作为速度、限位和停车辅助；不以无线 UI 状态替代本地安全判断。
- 飞机通过任务阶段与小车协同：伴随、投掷/降落阶段满足条件后允许小车提速；靠近 A 点时小车重新减速并停车。
- MaixCAM2 只输出平台识别结果和相对偏移；飞行、投掷、降落动作由飞控状态机决定。

## 使用原则

1. 不提交 `.pio`、Keil/PlatformIO 构建产物、串口临时日志、缓存、模型引擎和个人 IDE 状态。
2. 对跨端通信、飞行和停车结论，保留对应的串口/冻结日志或现场测试记录；源码不能替代实测证据。
3. 每一端在独立分支开发，经联调记录确认后再合入主分支。
