# 无人机端源码

本目录按空端职责保留可编辑源码：

- `ESP_LX_1/`：ESP32 空端通信桥、LoRa 协议与 USB/冻结日志相关源码；
- `ANO_LX/`：ANO 飞控与 STM32F407 工程源码；
- `树莓派地面站/`：地面站端代码与资源。

未纳入 PlatformIO、Keil 等构建产物、对象文件、私有 Git 元数据、缓存和打包文件。提交前的代码来源为 `F:\keil5\stm\无人机项目`。

## 任务实现要点

- ESP32 负责小车任务请求、LoRa 与飞控 LX UART 的桥接，并输出任务阶段、ACK 和串口诊断信息。
- 飞控任务状态覆盖起飞、拦截/伴飞、投掷对准与动作、降落对准、分级下降、平台停留 5 秒、再次起飞和返航；下降阶段具有步进节奏、终端距离和中止/直接降落保护。
- 第一轮任务由视觉目标偏移辅助对准和投放动作；第二轮任务采用平台对准后的分级下降与起飞流程。实际飞行效果应以串口冻结日志和现场记录验收，不以源码状态代替实测。
