# 视觉端源码

本目录是 `F:\keil5\stm\docs\视觉文件夹` 的源码快照，运行平台为 **MaixCAM2**，下视相机安装于无人机底部：

- `main.py`：视觉端主程序；
- `fc_simulator.py`：飞控联调模拟程序；
- `app.yaml`：应用配置；
- `项目描述.md`：项目说明。

已排除 `dist/` 中的打包 ZIP，保留可编辑源码与配置。

视觉端识别小车平台的大圈，向飞控提供相对 X/Y 偏移，用于伴飞跟踪、投掷前中心定位和动态起降引导；`main.py` 同时处理相机模式、目标回传与投放舵机动作。其作用是为俯冲/投掷和平台降落提供视觉定位，飞行动作本身仍由 `aircraft/` 的飞控状态机执行。
