# V2.3 维护复位协议补丁（待全端实现）

状态：本地草案，待审核；不得上传或部署到树莓派。

主规范为 [D题_通用通信与接口规范_v2.3.docx](D题_通用通信与接口规范_v2.3.docx)。在线帧的 `Version` 仍为 `0x02`；V2.3 是文档修订号，不另起帧版本。

## 协议差异

| 项目 | V2.3 定义 |
|---|---|
| 新消息 | `0x85 MAINTENANCE_RESET` |
| LoRa 方向 | 小车 `0x30` → 广播 `0x10` |
| ACK | 不请求、不回复 ACK |
| Payload | 8 B：`ResetId(u16)`、`ResetFlags(u8)`、`Reserved=0(u8)`、`SourceTimeMs(u32)` |
| 标志 | `ResetFlags.bit0=CLEAR_CALIBRATION`；其余位必须为 0 |
| 触发 | 小车物理维护复位按钮长按 2–3 s，且持续 `CAR_RUNNING=0` 至少 12 s |
| 重发 | 同一 `ResetId`、同一帧 `Seq` 连续发送 3 个小车时隙；后两帧设置 `RETRANSMISSION` |
| 时隙 | 只使用 0–25 ms 小车发送窗口 |

12 秒停车只是按钮生效条件。没有人工按键时，任何端都不得自动清除校准、解除发送锁或发送 `CALIBRATION_SET`。

## 小车端状态流

```text
已校准 / 任务后只收
  └─ 小车静止 ≥12 s 且人工长按 2–3 s
       └─ MCU 请求 Pi 清除 Δx/Δy、CALIBRATED、CalibrationId
            └─ Pi ACK 成功
                 └─ MCU 广播 0x85 三次
                      └─ Pi 持续发送未校准 CAR_POSE
                           └─ 地面站等待新鲜数据和人工二次确认
```

MCU 到 Pi 的本地请求也使用 `Type=0x85`：`Src=0x32`、`Dst=0x31`、`ACK_REQUIRED=1`，Payload 与广播帧一致。只有 Pi 清除成功并回复通用 ACK 后，MCU 才能把该帧改写为 `Src=0x30,Dst=0x10` 广播。

## 五端改动清单

| 端 | 必须改动 |
|---|---|
| 小车 MCU | 接入独立物理按钮；实现静止/长按判定、本地 Pi 清除握手、三帧无 ACK 广播及 `ResetId` 去重。按钮不控制起步、循线或任务重启。 |
| 小车 Pi | 识别本地 `0x85` 请求，清除内存校准偏移、`CALIBRATED` 与 `CalibrationId`，回复 ACK，恢复未校准 `CAR_POSE`。 |
| 机载 ESP32 | 校验 LoRa `0x85`，不回 ACK；新增 LX `SubType=0x05`，把 8 B Payload 原样转给飞控。 |
| 飞控 STM32 | 收到 `0x85` 或未校准 `CAR_POSE` 后失效小车校准输入；任务中按既有安全规则中止。飞控重新上电后，连续收到 3 帧同一有效校准 ID 的小车位姿即可复用。 |
| 树莓派地面站 | 新增“维护复位待人工确认”状态：取消待发校准、清空候选和旧完成状态；收到新鲜 IDLE 飞机、小车未运行且未校准数据后，仍要求人工二次确认，才允许一次校准发送。 |

## 校准复用规则

两个独立任务之间，只要小车 Pi 未掉电或重启，且平台坐标轴与安装关系没有变化，就保留同一套 `Δx/Δy`、`CALIBRATED=1` 和非零 `CalibrationId`。飞控重复上电不要求重新校准。

出现以下任一情况必须按物理维护复位并重新校准：小车 Pi/MCU 重启、坐标轴/安装关系改变，或需要人工清除旧校准。飞控重启本身不属于此条件。

## 固定测试向量

`ResetId=1`、`ResetFlags=0x01`、`SourceTimeMs=1234`、`Src=0x30`、`Dst=0x10`、`Seq=0x52`：

```text
AA 55 02 85 30 10 52 00 08 00 01 01 00 00 00 04 D2 9C B2
```

CRC16/CCITT-FALSE（从 `02` 至 `D2`）应为 `0x9CB2`。

## 验收与禁止项

- 运行中、停车不足 12 秒、短按：不得产生 `0x85`。
- 合格长按：Pi ACK 后才发送三帧；三帧的 `Seq`、`ResetId` 和 Payload 相同。
- 停车超过 12 秒但未按按钮：状态保持不变。
- 地面站收到新 `ResetId` 后，不得自动校准或自动发射。
- 飞控重启但小车未重启：收到连续 3 帧同一校准 ID 后可复用校准。
- 维护复位后：旧校准 ID、旧任务和重复 `0x85` 都不得恢复任务。
