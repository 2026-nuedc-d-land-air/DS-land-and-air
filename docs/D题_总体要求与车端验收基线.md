# D 题总体要求与车端验收基线

> **当前镜像：** `LineFollowMissionDebug`。
> **文档状态：** 2026-08-01 已按当前源码和串口 `P` 状态整理。本文是现场摘要；参数与状态机细节以 [`D题小车端实施基线.md`](D题小车端实施基线.md) 为准，V2.3 帧以 Word 规范为准。

## 1. 车端必须完成什么

1. 由车上的物理按键选择任务，在 A 点确认后启动；地面站只做显示和预飞校准，不能替代启动/停机。
2. 以八路灰度为横向循迹主传感器；编码器、JY901 航向和雷达位姿只做速度、转向与到点辅助，不能单独接管横向控制或强制停车。
3. 本地行驶不中断：无线 ACK、地面站显示丢失、飞行状态暂时过期均不能自行让小车停车。再次按任务键、循迹安全超时和电机安全故障才可以停车。
4. 在位姿有效时发布 `CAR_POSE(0x80)`，并以同一 `TaskType/MissionId` 请求飞行任务；车端不创建 `ModeSeq`、不发送相机控制帧，也不决定投掷/降落动作。
5. 现场结论必须由串口/冻结日志、时间或观测记录支撑，不能由“地面站显示正常”代替。

## 2. 当前运行合同

| 项目 | 当前实现 | 验收含义 |
| --- | --- | --- |
| 任务键 | `PG13` 任务一、`PG9` 任务二，低电平有效 | 仅空闲态接受选择；运行中任一任务键为本地急停。 |
| 起步 | 满足 A 点灰度与新鲜 JY901 后，按键起算 **20 s** 本地放行 | 不等待无人机 `FOLLOW`；预启动 `ABORT/REJECTED` 仍保持安全停。 |
| A→B 速度 | 任务一 `150 mm/s`，任务二 `170 mm/s` | 必须实测多次，确认小于赛题 15 s 且留裕量。 |
| 协同加速 | 任务一仅在匹配空中任务经过 `DROP_ACTION` 后到 `RETURN_HOME`；任务二在匹配 `PLATFORM_TAKEOFF(10)`（或后续阶段）**或本地已验证 D** 后解锁 | ACK、`FOLLOW`、原始 C/D 黑点均不解锁。任务二 D 必须同时满足 4650 mm 编码器路程和 1500（0.1°）累计转角。任务二由本地 D 解锁后，即使空中端随后报 `ABORT` 也保持速度锁存；任务一和任务二“空中阶段解锁”仍会因 `ABORT` 回协同速度。 |
| 快速包络 | 直线/缓弯/硬弯/急弯/丢线/宽线：`600/420/360/260/180/600 mm/s` | 这是当前源码参数，仍需按场地验证，不等同于比赛已通过。 |
| 丢线恢复 | 方向历史差速 `1400 cps`；首次中心捕获中和差速；连续 5 个 20 ms 中心样本才恢复；12 s 超时停机 | `F` 日志必须能区分恢复、方向反转和 `LINE_LOST_TIMEOUT`。 |
| D→A 预减速 | **任务二**路程 ≥`8000 mm` 即进入 `170 mm/s` A 接近速度；**任务一**仍要求路程 ≥`8000 mm` 且 yaw 距起始 yaw ≤`±30°`；两任务均以 `8800 mm` 为后备减速点 | 任务二的无航向预减速只限速度，不改变最终 A 停机门。 |
| A 点最终停机 | 编码器路程 ≥`8800 mm`，且回到起始航向附近后，接受全黑或稳定 7 路灰度；雷达仅可与中心灰度共同辅助 | B/C/D 都是宽黑点，距离门与航向门用于避免误停；灰度仍是最终位置主证据。 |
| 维护复位 | `PG12`：已停止 12 s 后短按触发本地维护复位并发送规定 `0x85` 三帧 | 不占用 PG9，不写雷达/Pi 校准状态；实际帧字段以 V2.3 Word 为准。 |

## 3. 硬件与数据源

| 链路 | 当前用途 | 不可越界项 |
| --- | --- | --- |
| 灰度 | `PC0/PC1/PC2` 选通 X1–X8，`PG0` 读取；中心 `X4|X5=0x18` | 不是 8 路 ADC，`PG1` 未使用。 |
| 前轮电机与编码器 | PWM `PA2/PA3`，方向 `PE2–PE5`，STBY `PE6`；编码器 `TIM5 PA0/PA1`、`TIM3 PA6/PA7` | PWM 寄存器变化不能替代车轮/编码器实测。 |
| JY901 | `USART2` 重映射 `PD5/PD6`，9600 | 是当前航向修正输入；未新鲜时不得起步。 |
| 雷达/Pi | `UART4 PC11` 接收，115200 | 只接收合规、已校准 `FIELD_GLOBAL` 位姿；过期阈值 250 ms；不能单独启动车辆或停车。 |
| LoRa | `UART5 PC12/PD2`，115200 | 在线 Version `0x02`；遵守 V2.3 时隙；只传车端职责帧。 |
| 诊断串口 | `USART1 PA9/PA10`，115200，当前接 `COM13` | `P/F/H` 是验收主证据入口。 |

## 4. 最小验收流程

1. **烧录后基线：** 读取 `P`，核对 20 s、`150/170`、`600/420/360/260/180/600`、`1400`、5 样本和 A 返回 `8000/8800/±300` 参数。
2. **单车循环：** 任务一、任务二分别从 A 启动；记录 A→B 时间、C/D 通过、D→A 接近减速、最终 A 停机原因和路程。
3. **丢线与宽点：** 在快速包络的弯段制造短暂丢线，确认先向历史方向恢复；B/C/D 黑点不得导致最终 A 停机。
4. **无线协同：** 以匹配任务号注入/接收有效空中阶段；确认非法阶段、单 ACK、`FOLLOW` 均不加速，合法阶段才解锁。
5. **故障与停机：** 验证二次任务键、丢线 12 s、运行 90 s 守护与 PG12 维护事件；每项保存一次 `F` 或完整串口输出。

## 5. 证据与当前限制

- 最近烧录后的 `P` 已能回读上述 A 返回和丢线参数；这只证明固件配置，不证明新的 D→A 现场策略已完成验收。
- 每轮运行结束立即保存 `F`：它应含 `terminal_reason`、`run_distance_mm`、灰度稳定掩码、当前 yaw、`a_heading_err` 和 `a_heading_near_start`。
- 若 A 点未停，先保留 `F`，再按“编码器路程 → 起始航向差 → 灰度稳定度 → 雷达中心辅助”的顺序定位；不要先改雷达阈值。
- 未闭环的赛题/协议事项见 [`D题_赛题合规差距清单_20260731.md`](D题_赛题合规差距清单_20260731.md)。
