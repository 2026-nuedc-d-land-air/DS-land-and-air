## 小车引脚对照（比赛镜像）

下表以 `car/Hardware/app_line_follow_mission.c`、`bsp_motor.*`、
`bsp_aux_tb6612.*`、`bsp_gray_tracking.*`、`bsp_gyro_wit.*` 和
`bsp_robot_uart.*` 为准；PCB 对照图见
[`hardware/小车pcb原理图展示.pdf`](hardware/小车pcb原理图展示.pdf)。

| 功能 | MCU 引脚 / 外设 | 备注 |
| --- | --- | --- |
| 前左/右电机 PWM | `PA2/TIM2_CH3`、`PA3/TIM2_CH4` | 前驱 TB6612，20 kHz。 |
| 前驱方向与待机 | `PE2/PE3`、`PE4/PE5`、`PE6` | 左 AIN、右 BIN、STBY。 |
| 前轮编码器 | `PA0/PA1 → TIM5`；`PA6/PA7 → TIM3` | 当前速度反馈来源。 |
| 后轮扩展 TB6612 | `PE13/TIM1_CH3`、`PE14/TIM1_CH4`；`PF1–PF4`；`PB9` | 后轮 PWM、方向、STBY；TIM1 全重映射。 |
| 后轮编码器预留 | `PB6/PB7`、`PC6/PC7` | 仅输入初始化；当前任务未轮询或闭环使用。 |
| 八路灰度 | `PC0/PC1/PC2 → AD0/AD1/AD2`；`PG0 ← OUT` | 74HC4051 选通扫描，`PG1` 未使用。 |
| JY901 姿态 | USART2 重映射：`PD5` TX、`PD6` RX | 9600 8N1。 |
| 树莓派/SL2 位姿 | UART4：`PC10` TX、`PC11` RX | 115200 8N1。 |
| LoRa / AS32 | UART5：`PC12` TX、`PD2` RX | 115200 8N1。 |
| 串口日志 | USART1：`PA9` TX、`PA10` RX | 115200 8N1，冻结日志读取证据。 |
| 任务按键 | `PG13` 任务一、`PG9` 任务二、`PG12` 维护复位 | 低有效；运行中再按任务键为急停。 |
| 任务指示灯 | `PG15`、`PG14`、`PE1` | 当前任务镜像使用的绿/备用/黄指示。 |

### PCB 对照结论

- PCB 已直接给出前驱 TB6612、前轮编码器、灰度模块、JY901、AS32、按键和指示灯连接。
- 原理图的扩展排针可引出 `PE13/PE14`、`PB9`、`PC6/PC7`；后驱方向线 `PF1–PF4` 的实际外接线束必须以实物通断测试为准。
- `PB9` 的旧 LED 驱动与 `PF1–PF4` 的旧直接灰度驱动不是当前比赛镜像的编译链，不能作为当前引脚冲突结论。
