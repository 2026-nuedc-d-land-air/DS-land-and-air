## 权威顺序

1. 当前接线、可重复的实测记录和当前烧录镜像；
2. 本目录的 `D题小车端实施基线.md`、引脚对照和项目维护规则；
3. 当前 C 源码及 `LineFollowMissionDebug` 构建产物；
4. [`D题_通用通信与接口规范_v2.3.docx`](D题_通用通信与接口规范_v2.3.docx)；在线帧 Version 仍为 `0x02`；
5. [`D题 回复.txt`](D题%20回复.txt)；
6. 历史笔记、旧实验和聊天转录。

发生矛盾时，不凭文档覆盖实测：记录引脚/状态、预期值、观察值和对应原始日志，再修订当前基线。

## 证据规则

- `P` 只证明当前镜像已加载的参数与状态；`F` 才是一次运行结束时的冻结证据；`H` 用于确认接收/发送的通信状态。
- “台架通过”“单机循迹通过”“车机联调通过”“比赛验收通过”必须分开表述，不能由地面站 UI 或单条 ACK 推导。
- 原始 `.log` 与冻结日志由现场采集端留存；历史 Markdown 笔记只归档、不作为当前参数来源。
- 每次现场运行至少保存：烧录配置、串口完整输出、场地/接线变化、任务号与结论。
- 本仓库保存照片和原理图；较大的任务视频以 SHA-256 索引，并通过 GitHub Release 或 Git LFS 关联。
