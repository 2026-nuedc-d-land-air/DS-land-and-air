## 证据规则

- `P` 只证明当前镜像已加载的参数与状态；`F` 才是一次运行结束时的冻结证据；`H` 用于确认接收/发送的通信状态。
- “台架通过”“单机循迹通过”“车机联调通过”“比赛验收通过”必须分开表述，不能由地面站 UI 或单条 ACK 推导。
- 原始 `.log` 保留在 `logs/`；历史 Markdown 笔记只归档、不作为当前参数来源。
- 每次现场运行至少保存：烧录配置、串口完整输出、场地/接线变化、任务号与结论。
