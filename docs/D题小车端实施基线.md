# D 题小车端实施基线

## 1. 目标与范围

本文件定义 D 题陆空协同系统的小车端运行态。小车以八路灰度循迹为主路径依据，编码器闭环负责速度，陀螺仪只做航向辅助，雷达/树莓派提供平台中心坐标给 LoRa 协同。小车不负责无人机的起飞、投放、着陆判定或飞控状态机。

## 3. 灰度循迹与速度策略

1. 已在实际白底黑线地图完成八头验证：`all_white_mask=0x00`，X1--X8 的激活位依次为 `0x01/0x02/0x04/0x08/0x10/0x20/0x40/0x80`，证据为 `logs/gray_mux_retest_20260730-104601.log`。正常黑线居中时 X4+X5 稳定为 `center_mask=0x18`，证据为 `logs/gray_mux_center_x4_x5_20260730-110625.log`；车体左/右偏时分别稳定为 X4=`0x08`、X5=`0x10`，证据为 `logs/gray_mux_vehicle_left_x4_20260730-111544.log` 与 `logs/gray_mux_vehicle_right_x5_20260730-111651.log`。误差诊断镜像重标定后的三点回归已通过：中心 `0`、左 `-100`、右 `+100`，证据为 `logs/gray_error_diag_*_20260730-112*.log`。诊断权重 `-7/-5/-3/-1/+1/+3/+5/+7` 的负值表示黑线在车体左、正值表示车体右。下一步只计算控制量、丢线和交叉线判定，再调 PID；未接入电机。旧 ADC 采样是错误驱动，不能作为当前映射结论。
2. A 点起始全黑区域已实测为稳定 `active_mask=0xFF`，证据为 `logs/gray_mux_all_black_A_20260730-110324.log`。该签名可用于路线位置确认；任务开始仍以车上实体按键为唯一触发条件。
3. 灰度阵列给出主横向误差；速度内环消费编码器反馈；陀螺仪 yaw 只做限幅修正，不替代灰度循迹。
4. A 到 B 为协同段。小车开始运动后计时，必须在 15 s 内到达 B。通过实际场地重复测量选择带余量的速度，不把“慢一点”作为无上限的策略。
5. B 后直线可采用独立的较高速度，弯道、丢线恢复和载荷不稳处必须降速。每个速度档都要记录速度、循迹误差、越线/丢线次数和停车距离。
6. 丢线时执行受限速度、按上次有效误差搜索并设置超时；无线 ACK、地面站显示和飞行状态都不应成为小车停车依据。

## 4. LoRa 与协同边界

树莓派将雷达/SLAM 坐标换算为车载平台中心的 `FIELD_GLOBAL` 位姿，并以 115200 8N1、10 Hz 发送给 MCU。MCU 校验后成为唯一 LoRa 发射者：

- 广播 `CAR_POSE`（0x80）10 Hz，坐标单位 cm、yaw 单位 0.1 度；
- 每个 100 ms 周期仅在 0-25 ms 的车端槽发射；30-55 ms 留给机端回应，55-100 ms 静默；
- 车上物理按键发起抛投或动态起降请求，固定任务 ID/序列最多重发三次；
- 只有 Pi 成功应用校准后才确认校准；任务中不得更改 `CalibrationId`；
- 任务中小车持续循线一整圈，不因 LoRa ACK、遥测延迟或地面站状态而重复启动或停车。

LoRa 模块的最终 MCU UART 仍待按实际接线确认，不在本文档假定。选择 UART 前必须检查日志、雷达、陀螺仪和 Pi 的已占用端口。

## 5. MaixCam V2.2 协同边界

MaixCam Pro 只与飞控进行 `CAMERA_MODE`、`CAMERA_TARGET`、`CAMERA_ACTION` 和
`CAMERA_ACTION_RESULT` 会话。飞控在接受小车任务后创建 `ModeSeq`，并以
`TaskType + MissionId + ModeSeq` 约束视觉目标和投放动作。小车 MCU 与树莓派：

- 只产生并保持 `CAR_TASK_REQUEST` 的 `TaskType/MissionId`，持续发送经 Pi
  校准的 `CAR_POSE`；
- 不生成或解析 `ModeSeq`，不解析相机 TARGET/RESULT，不直接驱动相机或投放舵机；
- 不因相机模式 ACK、视觉目标丢失、投放 RESULT 或遥测延迟停止、重启或改变循迹。

雷达/Pi 位姿仍是空地协同的主闭环输入；MaixCam 仅在飞控已建立有效会话后的末段
提供机体系纠偏。

## 6. 运行态与验收

```text
IDLE -> 起飞前校准 -> 车上按键选任务 -> A-B 灰度循迹/位姿10Hz
     -> 其余赛道循迹/伴飞 -> 完成或安全停止
```

最小验收证据：

| 项目 | 必须记录 |
| --- | --- |
| 灰度阵列 | X1--X8 地址扫描位号、`all_white_mask`、地图白黑极性、误差符号、丢线策略；记录每头 `CHANNEL_SWITCH` 日志 |
| A-B | 场地版本、至少多次用时、选定速度和 15 s 余量 |
| 电机 | 指令方向、实际方向、编码器符号、最大安全 PWM |
| LoRa | 帧类型、序列、CRC、位姿年龄、时隙时刻、重发次数 |
| 任务按钮 | 任务类型、任务 ID、单次触发和去重结果 |
| 空地会话边界 | 小车任务 ID 与飞控/相机状态匹配记录；无小车直接相机控制 |

地面站只显示场地、小车、无人机、链路新鲜度和校准/任务状态。任务运行期间不应提供小车启动、停止、调参或代码下发控制。
